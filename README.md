# Source of Trust

Standardizing how websites become discoverable, understandable, and trustworthy for AI systems.

---

Welcome to the official community and feedback repository for **Source of Trust**. We focus on defining and measuring AI visibility through **GEO (Generative Engine Optimization)**, **AEO (Answer Engine Optimization)**, and verified **Trust Signals**.

## 🚀 Purpose of this Repository

This public repository serves as our transparent hub for community interaction. Since trust and transparency are the foundations of the next generation of the web, we open-source our community feedback loop.

Currently, you can use this repository to:
* **Report Issues & Bugs:** Let us know if something on our platform or validation tools isn't working as expected.
* **Suggest Trust Signals:** Share ideas on which data points and schemas AI engines should prioritize to evaluate website credibility.
* **Discuss GEO/AEO Best Practices:** Engage with the community on how to optimize content for LLMs and AI search engines.

## 🐛 How to Report a Bug or Share Feedback

We highly value community feedback. To report an issue, please follow these steps:

1. Navigate to the [Issues](https://github.com/eeoom/source-of-trust/issues) tab at the top of this page.
2. Click on the green **"New Issue"** button.
3. Provide a clear description of the issue, steps to reproduce it, and (if applicable) which AI engine or browser you were using.

## 😎 Awesome AI Trust & GEO Resources

A curated list of research papers, tools, and specifications defining website trustworthiness and discoverability for AI systems.

### 📄 Research & Academic Papers
* [GEO: Generative Engine Optimization](https://arxiv.org/abs/2311.09735) — The foundational research paper on how to optimize content for LLM-based search engines.
* [LLMs as Evaluators: A Novel Approach to Evaluate Bug Report Summarization](https://arxiv.org/abs/2409.00630) — Research on how large language models can be used to evaluate and judge information quality.

### 🛠️ Industry Tools & Validators
* [Schema.org Validator](https://validator.schema.org/) — The official tool to test Organization, Brand, WebSite, WebPage and other schema markup.
* [Google Rich Results Test](https://search.google.com/test/rich-results) — Google’s tool for verifying structured data eligibility for rich results.

### 🤖 Official AI Bot Documentation
* [OpenAI Crawlers / OAI-SearchBot](https://developers.openai.com/api/docs/bots) — Official documentation for OpenAI’s web crawlers, including OAI-SearchBot and GPTBot.
* [Anthropic ClaudeBot](https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler) — Official Anthropic documentation on ClaudeBot and related crawlers.
* [Perplexity Crawlers / PerplexityBot](https://docs.perplexity.ai/docs/resources/perplexity-crawlers) — Official Perplexity documentation for PerplexityBot and crawler access behavior.

### 🤝 How to Contribute
This is an open, community-driven list. If you want to add valuable papers, tools, or resources regarding GEO, AEO, or AI Trust Signals, please open an Issue or submit a Pull Request!
